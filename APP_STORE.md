# App Store Publishing

## Setup

1. Enroll in the Apple Developer Program.
2. Create an App Store Connect record for SecondBrain AI.
3. Configure bundle identifier and App Store settings.

## Build

1. Use Android Studio or command line to generate Android artifacts for Play Store.
2. For iOS support, create a separate Xcode iOS project with matching backend integration.

## Metadata

1. Provide app name, description, screenshots, and keywords.
2. Set supported languages and privacy information.

## Submission

1. Upload the release binary to App Store Connect.
2. Complete pricing, availability, and compliance checks.
3. Submit for review and monitor status.
